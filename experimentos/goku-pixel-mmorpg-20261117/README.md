# DragonRealm · Goku Pixel RPG (prototipo)

Juego 2D interactivo para celular y computadora, inspirado en la imagen de pixel art de Goku en un mapa estilo RPG/MMORPG que Gonzalo creó en ChatGPT.

**[Jugar en línea](https://raw.githack.com/gvelazcamp/videos-ia/main/experimentos/goku-pixel-mmorpg-20261117/index.html)**

## Controles

- **Celular:** cruceta para caminar; botón A para hablar o interactuar; botón B para combatir.
- **Teclado:** flechas o WASD para caminar; E o Enter para interactuar; barra espaciadora para atacar.
- Explorá, hablá con NPC, luchá contra criaturas y encontrá las siete esferas doradas.
- Nivel/XP/vida, minimapa, misiones, tienda de curación y guardado local de partida.

## Arquitectura

Solo un archivo HTML, CSS y JavaScript (Canvas 2D), sin dependencias, servidores, pagos ni API.

Los elementos del escenario se dibujan por código y tienen colisiones y lógica; **no es una imagen estática con controles superpuestos**.

## Referencia original

La imagen de referencia fue generada por ChatGPT el 17/11/2026, PNG de 941 × 1672. No está incorporada como PNG original en este repositorio todavía; el juego reinterpreta su concepto visual.

## Alcance

Primera demo **local**; MMORPG se refiere al estilo gráfico de la inspiración y no a multijugador funcional. No se modificaron otros juegos.
